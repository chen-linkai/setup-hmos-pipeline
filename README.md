# Setup HmOS Pipeline

## Usage

```yaml
- uses: chen-linkai/setup-hmos-pipeline@v1
  with:
    version: 'latest' # The target version of the Command Line Tools, e.g. "6.1.1.300", or the "latest" alias to use the newest available stable release.
    java-distribution: 'oracle' # See https://github.com/actions/setup-java/tree/main#supported-distributions.
```
